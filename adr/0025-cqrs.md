# ADR-0025: CQRS and application execution

Status: Proposed

Date: 2026-10-05

## Context

Agents need a clear command/query structure without treating CQRS as an alternative to HTTP APIs.

## Decision

Default to logical CQRS in the existing module/backend/store; use application-owned handlers or methods and projections.

## Alternatives

A uniform CRUD service is adequate for simple features when methods preserve the separation. Separate stores/event sourcing add complexity and require independent justification.

## Consequences

More explicit use-case types improve ownership but can add ceremony. Distributed read models require consistency and recovery operations.
