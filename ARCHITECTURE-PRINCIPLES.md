# Architecture principles

Version: 0.1.0 draft.

1. Independent frontend and backend ownership, repositories, builds, releases, and rollback.
2. Explicit, versioned contracts connect applications.
3. Data has a named owner and controlled access.
4. Prefer the simplest design that satisfies measured requirements.
5. Security, operability, accessibility, and recovery are design inputs.
6. Decisions include rationale, alternatives, consequences, and verification.
7. Automate objective rules and review contextual decisions.
8. Pin standards; adopt changes deliberately.

Only decisions marked Accepted in the ADR index are established owner decisions. The remaining baseline is a proposed design for review.
